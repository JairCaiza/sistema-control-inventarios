# Sistema de Gestión de Procesos Productivos

## Descripción

Aplicación web desarrollada para la gestión de procesos productivos de una empresa dedicada al alquiler y administración de equipos. El sistema integra diferentes módulos de negocio y constituye la base para la implementación de una plataforma DevOps basada en una arquitectura de microservicios.

## Tecnologías utilizadas

### Backend

- Node.js
- Express
- PostgreSQL
- JWT
- Joi

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

### Base de datos

- PostgreSQL

## Módulos implementados

- Seguridad
- Inventario
- Clientes
- Contratos de alquiler
- Devoluciones
- Gestión de obras
- Finanzas
- Socios
- Auditoría

## Estructura del proyecto

```text
SistemaControlInventarios
│
├── back
├── frontend
└── database
```

## Estado actual del proyecto

- Sistema funcional en entorno local.
- Backend y frontend integrados mediante API REST.
- Base de datos PostgreSQL estabilizada mediante un script de inicialización.
- Preparado para iniciar el proceso de contenerización con Docker y la implementación de prácticas DevOps.
